# FortunaForge

A complete browser-based idle progression game. Reveal Fortune Cards, earn resources, unlock perks, and ascend your destiny.

## How to Play

1. Open `index.html` in any modern browser.
2. Click **REVEAL FORTUNE** to earn Coins and resources.
3. Unlock higher card tiers by revealing more cards.
4. Spend **Perk Points** in the Perk Tree to gain permanent bonuses.
5. When progress slows, perform a **Destiny Ascension** to earn **Essence** and unlock powerful permanent perks.
6. Repeat and grow stronger forever.

## Hosting on GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html` to the repository.
3. Go to **Settings > Pages** and select the branch you uploaded to.
4. Your game will be live at `https://yourusername.github.io/repositoryname/`.

## Save System

- The game automatically saves to your browser's LocalStorage.
- Use the **Export** button in Settings to create a backup string.
- Use the **Import** button to restore from a backup.
- Use **Reset** to wipe all progress and start fresh.

## Features

- 9 unique Card Tiers with CSS-generated artwork
- 50+ Perks across 5 branches (Luck, Speed, Wealth, Discovery, Prestige)
- 100 Achievements
- 5 Special Events
- 6 Unlockable Themes
- Procedural generative music (Forge Radio)
- Particle effects
- Combo system
- Destiny Ascension (Prestige)
- Fully responsive (Mobile & Desktop)
- No external assets or dependencies

## Controls

- **PC**: Use the sidebar to navigate.
- **Mobile**: Use the bottom navigation bar.
- **Audio**: Toggle music and sound in Settings.

Enjoy the Forge!
